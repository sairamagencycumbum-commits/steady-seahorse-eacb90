SAIRAM AGENCY WEBSITE — QUICK START

Files:
- index.html: the complete responsive website.

BEFORE PUBLISHING:
1. Open index.html in a text editor (Notepad is fine).
2. Find this line:
   const WHATSAPP_NUMBER = "91REPLACE_WITH_YOUR_NUMBER";
3. Replace it with your WhatsApp Business number in international digits only.
   Example format: "919876543210" (illustration only).
4. Save the file.
5. Check the shop address and update it in the Contact section if you want a full address shown.
6. Open index.html in a browser to preview it.

DEPLOY TO NETLIFY:
1. Sign in at https://app.netlify.com/
2. Look for Add new site / Add new project / Deploy manually.
3. If the manual deploy page asks for a folder, upload the folder containing index.html.
   If it asks for a ZIP, upload sairam-agency-website.zip.
4. Wait for the temporary *.netlify.app site address and open it.
5. Test on a phone and click the WhatsApp buttons.

CUSTOM DOMAIN:
1. In your Netlify site, open Domain management / Domains.
2. Add sairamagencycumbum.in.
3. Follow the DNS instructions shown in your own Netlify dashboard.
4. In GoDaddy Domain Portfolio > sairamagencycumbum.in > DNS, add the exact records Netlify gives you.
5. Do not delete MX/TXT records used for email. Verify the domain in Netlify and wait for DNS propagation.
